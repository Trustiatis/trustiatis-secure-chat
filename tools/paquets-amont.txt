# Paquets de bureau officiels de l'amont, dont on extrait les bibliothèques du coeur.
#
# Pourquoi ce fichier existe : la décision D-2 dit que le coeur Haskell n'est jamais
# recompilé. Or scripts/desktop/build-lib-{linux,mac,windows}.sh, qui viennent de l'amont,
# le recompilent (cabal build) et exigent une chaîne GHC complète, plus un MinGW très
# précis sur Windows. On prend donc les bibliothèques déjà compilées par l'amont, dans ses
# paquets publiés, exactement comme on l'a fait pour Linux et pour Android.
#
# Les empreintes sont celles que l'API de GitHub publie pour chaque actif de la version
# (champ `digest`). Les relever à nouveau à chaque changement de base d'amont :
#
#   curl -s https://api.github.com/repos/simplex-chat/simplex-chat/releases/tags/<tag> \
#     | python3 -c 'import json,sys; [print(a["name"], a.get("digest")) for a in json.load(sys.stdin)["assets"]]'
#
# La base d'amont elle même est dans tools/amont-courant.txt, et c'est elle qui fait foi :
# ne pas écrire le tag deux fois.
#
# Pourquoi le paquet Ubuntu 22.04 et non celui de 24.04 : c'est celui dont les
# bibliothèques ont servi à la compilation Linux déjà éprouvée sur ce poste, et c'est aussi
# celui qui vise la plus ancienne glibc des deux. Les deux paquets portent les mêmes
# versions de paquets Haskell mais aucun fichier commun, octet pour octet : en changer
# reviendrait à refaire la vérification du paquet livré.
#
# Colonnes : cible | dossier de bibliothèques | lien attendu par Compose | actif | sha256
#
# « cible » est ce qu'on passe à scripts/desktop/libs-depuis-amont.sh.
# « dossier » est relatif à apps/multiplatform/common/src/commonMain/cpp/desktop/libs/.
# « lien » est relatif à apps/multiplatform/build/links/, et ces noms ne sont pas libres :
# Compose Desktop les compose lui même à partir du système et de l'architecture.
